# DeskLink 로드맵

DeskLink(맥 서버 ↔ 안드로이드 확장 디스플레이)의 향후 개선 계획. 우선순위는 "체감 완성도"를 빠르게 끌어올리는 순서.

## 1순위 — 코어 UX 마무리

- **해상도 변경 시 재적용**: 재연결 시 클라이언트가 새로 선택한 해상도로 가상 디스플레이·인코더를 재구성(리부트). 해상도가 바뀔 때만 재생성하고, 비트레이트만 바뀌면 `updateBitrate`로 처리.
- **맥 Settings 창 구현**: 현재 "Settings..." 버튼이 빈 스텁. 포트, 기본 해상도, 자동 시작, 코덱 등 설정.
- **연결 상태 HUD (태블릿)**: 해상도·FPS·비트레이트·E2E 지연을 화면에 작게 표시. 튜닝/디버깅에 유용.
- **재연결 UX 다듬기**: 상태 메시지 명확화, 수동 재연결 버튼, 미러링 화면의 연결 끊기/설정 오버레이(완료).

## 2순위 — 화질·입력 품질

- **적응형 비트레이트**: 이미 정의된 `BITRATE_UPDATE` 메시지를 활용해 네트워크/CPU 상황에 따라 비트레이트를 자동 조절 → 끊김 감소.
- **HiDPI(레티나) 렌더링**: 가상 디스플레이를 2x 스케일로 만들어 글자·선 선명도 향상.
- **스타일러스/필압 + 키보드 입력**: 펜 좌표·필압 전송, 태블릿 키보드 → 맥 키 입력 역전송.

## 3순위 — 배포·안정성

- **보안/페어링**: 현재 연결에 인증 없음. 페어링 코드/토큰 추가(특히 Wi-Fi 모드에서 중요).
- **Wi-Fi 모드 다듬기**: mDNS/Bonjour로 서버 자동 검색 → IP 수동 입력 제거.
- **정식 앱 패키징 + 공증(notarization)**: 배포용 .dmg. 단, `CGVirtualDisplay`가 비공개 API라 App Store 배포는 불가.
- **자동 시작 / 메뉴바 다듬기**.

## 추천 진행 순서

해상도 재적용 → 연결/화질 HUD → 적응형 비트레이트 → HiDPI.

## 완료

- **오디오 전송 (완료)**: 신규 Audio 채널(포트 7103, `AUDIO_CONFIG` 0x30 / `AUDIO_FRAME` 0x31)로 맥
  시스템 오디오를 태블릿에 전송한다. 상세는 `docs/protocol-spec.md` §6.
  - ScreenCaptureKit의 `capturesAudio`가 아니라 **Core Audio 프로세스 탭**(macOS 14.2+,
    `CATapMutedWhenTapped`)을 쓴다. SCK는 오디오를 복사만 하고 로컬 재생을 막을 수 없어 맥과
    태블릿에서 동시에 소리가 나고 전송 지연이 에코로 들린다. 탭은 읽는 동안 출력 장치로 가는
    경로를 끊으므로 "태블릿에서만 재생"이 성립하고, 읽기를 멈추면 OS가 로컬 재생을 자동 복구한다.
  - 립싱크: 비디오가 마스터 클럭이다(미러링은 지연이 목적이라 프레임을 도착 즉시 렌더). 오디오·비디오
    타임스탬프가 동일 축(호스트 가동 시간 µs)을 공유하고, 태블릿이 렌더된 프레임에서 server→local
    오프셋을 학습해 오디오를 그 축에 맞춘다.
  - 기본값은 **꺼짐**. 켜면 연결 중 맥 스피커가 무음이 되므로 사용자가 명시적으로 선택해야 한다.

## 알려진 제약

- `CGVirtualDisplay`는 비공개 API → macOS 버전 의존성, App Store 배포 불가, 잦은 재생성 시 불안정 가능.
- 맥 앱은 화면 기록·손쉬운 사용 권한을 위해 서명된 .app로 실행해야 함(개발용 자체 서명 인증서 사용 중).
- 오디오 캡처는 macOS 14.2+ 전용이며 별도 TCC 승인(`NSAudioCaptureUsageDescription`)이 필요하다.
  서명되지 않은 바이너리(예: `swift test`)에서는 승인이 없어 `AudioDeviceStart`가 실패하므로,
  오디오 경로의 종단 검증은 서명된 .app에서만 가능하다.
- 오디오는 무압축 PCM으로 보낸다(48 kHz/16-bit/스테레오 ≈ 1.54 Mbps). USB `adb reverse`에서는
  무해하고 인코더/디코더 지연이 0이지만, Wi-Fi 전송을 붙일 때는 Opus/AAC 옵션이 필요하다.
